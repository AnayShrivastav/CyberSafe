CyberSafe --- Online Fraud Awareness

CyberSafe is an educational website created as part of a B.Sc.
Information Technology Community Engagement Project. It aims to raise
awareness about phishing, online scams, and digital fraud through clear
explanations, practical safety tips, and interactive activities.

Live Website
Once GitHub Pages is enabled for this repository, the website should be
available at:
https://anayshrivastav.github.io/CyberSafe/

If the link does not open, check the repository's Settings → Pages
and the latest deployment in the Actions tab.

Project Objectives
- Build awareness of common online scams and fraud.
- Help users recognize suspicious messages, links, and requests.
- Encourage safer practices when using websites, social media, and
  digital payment services.
- Collect responses through a cyber-awareness survey for academic
  analysis.
  
Features
- Home page: Introduction to cyber safety, common threats, and
  recommended safety habits.
- About page: Project background, objectives, and intended
  audience.
- Types of Scams: Information about phishing, payment scams, fake
  job scams, online shopping scams, OTP scams, and fake customer-care
  scams.
- Scam Detection Activity: An interactive example message that
  users can classify as safe or suspicious, followed by feedback.
- Online Safety Tips: Guidance on password security, OTP
  protection, checking links, device updates, and two-factor
  authentication.
- Cyber Safety Quiz: Five multiple-choice questions with a score,
  percentage, and feedback.
- Cyber Awareness Survey: A link to a Google Form for collecting
  survey responses.
- Contact & Feedback: A link to a Google Form for feedback.
- Responsive navigation: A shared navigation bar with a
  collapsible menu for smaller screens.
- Visual effects: A subtle animated network-particle background,
  with reduced-motion preference respected.

Technology Stack
- HTML5 --- page structure and content
- CSS3 --- styling, layouts, responsive presentation, and visual
  effects
- JavaScript (Vanilla) --- navigation behavior, quiz scoring,
  scam-detection feedback, and animation
- Google Fonts (Inter) --- typography
- Google Forms --- survey and feedback collection
- GitHub Pages --- static website hosting
No frontend framework or package installation is required.
Run Locally
1. Download or clone this repository.
2. Keep all HTML, CSS, and JavaScript files together in the same
   directory.
3. Open index.html in a web browser.
For a more consistent local development experience, you can use the Live
Server extension in Visual Studio Code.
Deploy with GitHub Pages
1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and the /(root) folder.
5. Save the settings and wait for the deployment to finish.
6. Open the published URL shown on the Pages settings screen. You can
   check deployment status under Actions.
After pushing changes to the configured branch, GitHub Pages will
rebuild the site.

Survey and Feedback
The project links to Google Forms for survey participation and feedback.
Responses are collected through those external forms, rather than
through a custom backend in this repository.
- Cyber-awareness survey: Linked from survey.html
- Feedback form: Linked from contact.html

Important Notes
- CyberSafe is an awareness and educational project. The
  scam-detection activity demonstrates warning signs using a sample
  message; it is not an automated scanner and does not verify real
  URLs or messages.
- The quiz runs in the browser. Its score is displayed on the page and
  is not submitted to a server by the included code.
- The website is a static frontend and does not include a database,
  user accounts, or a custom backend.
- External Google Forms and Google Fonts require an internet
  connection.
- The information provided is for general awareness and should not
  replace verification through official sources.
  
Intended Audience
The project is intended for students, parents, senior citizens,
digital-payment users, social-media users, and other internet users who
want to improve their awareness of online scams.
